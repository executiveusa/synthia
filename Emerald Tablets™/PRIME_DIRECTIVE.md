# Emerald Tablets™ Prime Directive

## Purpose

This folder holds the repository governance standard for `Emerald Tablets™`.
It defines how the codebase is handled, reviewed, and verified.

## Rules

- Truth first: do not present assumptions as facts.
- Scope first: keep changes narrow and intentional.
- Verify first: run the smallest useful test or build check after edits.
- No secrets in source control.
- No barrel files unless the repo already uses them for a reason.
- No god files that absorb unrelated responsibilities.
- No deploy without a health check or build verification.
- No duplicate architecture when a working pattern already exists.
- Reuse `OpenChronicle/` only as reference material.

## Branding

All documentation references must use `Emerald Tablets™` and `SYNTHIA™ 3.0` where those names appear.

## Commit Discipline

Use small, reviewable commits. When architecture changes are involved, explain the leverage point and the verification method.
