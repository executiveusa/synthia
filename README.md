SYNTHIA™ is an **autonomous AI-powered platform** designed specifically for Mexican women entrepreneurs. It combines:

## 🚀 Quick Start

### Prerequisites

- Node.js 22+
- Python 3.11+
- MySQL 8+ or TiDB
- pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/executiveusa/synthia.git
cd synthia

# Install dependencies
pnpm install

# Set up environment variables
# (Contact Kupuri Media for credentials)

# Push database schema
pnpm db:push

# Start development server
pnpm dev

# Start autonomous engine (separate terminal)
cd ../synthia-core
python main.py
```

## 🎮 Command Center Features

### Live Agent Monitoring
Real-time window showing exactly what SYNTHIA™ is doing:
- Current task execution
- Decision tree visualization
- Agent Lightning supervision status
- Step-by-step progress

### Canonical Logging
Every action is logged and reversible:
- Complete audit trail
- Rollback any decision
- Decision replay (see why SYNTHIA™ chose something)
- Version control for all changes

### Infinite Memory (ByteRover)
One memory agent per customer:
- Remembers all interactions
- Learns preferences over time
- Personalized service
- Separate containers for service/sales

### LiteLLM Multi-Model Backend
Switch between AI models:
- GPT-4 (strategic decisions)
- Claude (creative content)
- Gemini (data analysis)
- Cost optimization
- Fallback redundancy

### Google Services Integration
- **Trends**: Real-time trending topics per region
- **Maps**: Geo-targeting visualization
- **Ads**: Campaign management
- **Analytics**: Performance tracking

### Voice Commands
Control SYNTHIA™ by voice:
- "Show me Mexico City campaign performance"
- "Stop all underperforming ads"
- "Generate new landing page for Puerto Rico"
- "What's SYNTHIA™ working on right now?"
- "Rollback last decision"
